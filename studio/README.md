# Sanity Studio – vandenhoeck.de

Projekt `4y4m7dt1`, Dataset `production` (öffentlich). Gehostet auf https://vandenhoeck.sanity.studio.

- `npm run dev` – Studio lokal (http://localhost:3333)
- `npm run deploy` – Studio veröffentlichen
- `npm run typegen` – Schema extrahieren und Typen für `web/lib/sanity.types.ts` erzeugen

Inhaltstypen: Seiteneinstellungen (Singleton), Deepdives, Ressourcen, Seiten.
`seed/initial-content.ts` hat am 20.10.2026 die bis dahin statischen Inhalte übernommen
(nicht erneut ausführen, überschreibt Änderungen aus dem Studio).
